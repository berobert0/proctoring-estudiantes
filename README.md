# Proctoring Estudiantes

Frontend educativo de evaluación supervisada.

Incluye cámara, pantalla completa, bloqueo básico de copiar/pegar, detección de cambio de pestaña, pérdida de foco, salida de pantalla completa, contador de incidencias y marca de agua.

## Importante
Las protecciones hechas solo con HTML/JavaScript no impiden completamente capturas de pantalla, grabaciones externas, otro dispositivo ni manipulación avanzada del navegador. Para uso real, agrega backend, autenticación, base de datos, almacenamiento de evidencias y política de privacidad.
